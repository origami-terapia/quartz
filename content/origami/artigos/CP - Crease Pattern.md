# CP - Crease Pattern



CP - Crease pattern Apenas uma introdução para os que não conhecem um conceito diferente de diagramação de modelos de origami o Crease Pattern. Mas o que é esse padrão de dobras, mapa, todos passos do origami em uma única imagem? Uma coisa é certa, dessa forma consegue-se inventar modelos muito mais complexos, mas também para entender e dobrar é com certeza mais dificil, pois exige além de ter uma base no origami, também ter o olhar como que no xadrez, pois quando você olha o mapa pelo desenho das dobras você já consegue imaginar o que é cada parte. É dificil explicar, mas uma vez aprendido, as possibilidades são inúmeras. Para ilustrar logo abaixo tem links para vocês poderem ver. Tem um grupo no yahoogrupos que é só sobre isso, grupoorigamipatrones, para quem quiser tem o endereço logo abaixo. Ja inventei alguns origamis usando esse método e posso dizer que as possibilidades aumentaram significativamentes. Robert Lang, tem um programa em seu site que é só para isso, realmente não sei nem começar. Mas o que é Crease Pattern? podemos defini-lo por algumas de suas características, na verdade ainda não se tem uma definição exata do que seja. Uma representação gráfica de dobras, vale e montanha. Um mapa? Usamos uma folha de papel para tudo isso e muitos cp vem diferenciando vale e montanha, outros não...
